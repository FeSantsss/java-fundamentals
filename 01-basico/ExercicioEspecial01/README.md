# 🧮 Sistema de Renda de Funcionário em Java

Este projeto foi desenvolvido como parte dos estudos de Java com foco em **Orientação a Objetos**. A aplicação simula um sistema de gerenciamento de contratos por hora de um funcionário, permitindo calcular a **renda mensal** com base em contratos realizados e no salário base.

## 🚀 Funcionalidades

- Cadastro de funcionário com nome, nível e salário base.
- Associação de funcionário a um departamento.
- Registro de múltiplos contratos com:
  - Data
  - Valor por hora
  - Duração em horas
- Cálculo da renda total de um mês específico.

## 🛠️ Tecnologias

- Java (JDK 8+)
- Orientação a Objetos
- API `java.time` (`LocalDate`, `DateTimeFormatter`)
- Scanner para entrada de dados via terminal
