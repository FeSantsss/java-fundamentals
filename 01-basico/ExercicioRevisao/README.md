# 💻 Sistema Bancário em Java

Este projeto é uma simulação de um sistema bancário simples feito totalmente em Java. 
O objetivo principal foi consolidar os conceitos de orientação a objetos, controle de fluxo, encapsulamento, modularização e boas práticas em projetos Java de console.

---

## 🚀 Funcionalidades

- Criar uma nova conta bancária com número, titular e saldo inicial
- Realizar depósitos e saques com validação de valores
- Exibir os dados completos da conta, incluindo data de criação
- Menu interativo com opção de continuar ou encerrar o programa

---

## 🧠 Conceitos aplicados

- Orientação a Objetos (POO)
- Encapsulamento de dados
- Estrutura modular (separação por pacotes)
- Manipulação de datas com `LocalDateTime`
- Boas práticas com `try-with-resources` e tratamento de exceções
- Interação via console com o usuário

---

## 🗂 Estrutura do projeto
src/
├── application/
│ ├── Program.java # Ponto de entrada da aplicação
│ └── menuSystem.java # Sistema de menu com interações
├── model/
